# Grand Lodge Ghana 2026

Web project for the Grand Lodge of Ghana 2026 initiative.

This repository hosts the build of the Grand Lodge Ghana 2026 site, published automatically via GitHub Pages (see the **Production** deployment link in the right sidebar of the repo page).

## Live site

The site is deployed from this repository. Open the **Production** link under *Deployments* on the right of the repo page to view it.

## What's in this repo

- `grand-lodge-ghana2026-fixed.zip` — the packaged build of the site (HTML, CSS, JavaScript, and assets). Download and unzip to view the source locally or to redeploy.

## Run / view locally

1. Click the zip file in the file list above and choose **Download**.
2. Unzip it on your machine.
3. Open `index.html` in any modern browser.

That's it — the project is a static site, no build step or server required.
